# 七鱼接入飞书客户群 操作手册

## 一、概述

本手册说明如何将飞书群接入网易七鱼智能客服，实现客户在飞书群内提问、客服在七鱼工作台统一接待。

接入完成后：

- 客户在飞书群中 @ 客服机器人即可发起咨询
- 客服在七鱼工作台接收、回复、转交、结束会话
- 会话统一进入七鱼会话记录，支持质检、统计与满意度评价
- 支持文本、图片、文件、富文本、引用消息、表情、位置等消息类型

**版本要求**：七鱼专业版或旗舰版。标准版不支持飞书渠道。渠道接入不额外收费。

**配置入口**：七鱼后台 → 在线客服 → 在线接入 → 飞书接入 → IM 消息

---

## 二、接入前准备

### 2.1 人员与权限

| 角色 | 需要具备的权限 | 负责环节 |
|---|---|---|
| 飞书管理员 | 飞书企业管理后台权限 | 创建应用、审核发布 |
| 七鱼管理员 | 在线接入、扩展与集成菜单权限 | 渠道配置、会话分配 |

普通客服账号无法看到上述菜单，需使用管理员账号或已授权的子账号。

### 2.2 需要准备的信息

| 信息 | 获取位置 |
|---|---|
| App ID | 飞书应用 → 凭证与基础信息 |
| App Secret | 飞书应用 → 凭证与基础信息 |
| Encrypt Key | 飞书应用 → 事件与回调 → 加密策略 |
| Verification Token | 飞书应用 → 事件与回调 → 加密策略 |

### 2.3 建议提前确认

- 飞书企业状态正常，无欠费或功能限制
- 准备一个测试群，用于接入后验证
- 准备一个飞书内部账号与一个外部联系人账号，分别测试客服侧与客户侧

## 三、接入步骤

> 以下六个步骤请按顺序执行。顺序颠倒会导致回调地址无法生成或事件订阅验证失败。

### 步骤一：创建飞书应用

**操作位置**：飞书开发者后台

1. 点击创建应用，选择「企业自建应用」
2. 填写应用名称、描述并上传图标
3. 创建完成后进入应用详情页

**命名建议**

该应用的名称与头像会展示在客户所在的飞书群中，建议使用客户可识别的业务名称，例如「XX官方客服」「XX售后助手」，避免使用内部代号。

### 步骤二：在七鱼绑定应用

**操作位置**：七鱼后台 → 在线客服 → 在线接入 → 飞书接入 → IM 消息 → 绑定飞书应用

将 2.2 中的四项信息填入对应字段并保存。

保存成功后，系统会自动生成一个**回调请求地址**，请立即复制，下一步需要使用。

如未生成地址，请检查 App ID 与 App Secret 是否填写正确、是否含多余空格。

### 步骤三：回填回调地址

**操作位置**：飞书应用 → 事件配置、回调配置

1. 将上一步生成的回调地址填入「事件配置」的请求地址
2. 将同一个地址填入「回调配置」的请求地址
3. 订阅方式选择「将回调发送至开发者服务器」
4. 保存

两个页面填写的是同一个地址。保存后飞书会进行地址校验，校验通过即配置成功。

### 步骤四：开通能力、权限与事件

本步骤包含三项配置，需全部完成。

#### （一）添加机器人能力

飞书应用 → 添加应用能力 → 机器人 → 添加

#### （二）开通权限

飞书应用 → 权限管理 → 开通权限，勾选以下九项：

| 权限名称 | 权限标识 |
|---|---|
| 获取通讯录基本信息 | contact:contact.base:readonly |
| 获取用户基本信息 | contact:user.base:readonly |
| 获取用户 user ID | contact:user.employee_id:readonly |
| 获取与更新群组信息 | im:chat |
| 获取与发送单聊、群组消息 | im:message |
| 接收群聊中@机器人消息事件 | im:message.group_at_msg:readonly |
| 读取用户发给机器人的单聊消息 | im:message.p2p_msg:readonly |
| 获取与上传图片或文件资源 | im:resource |
| 获取群组中用户和机器人发送的消息 | im:message.group_msg.include_bot:read |

其中最后一项属于敏感权限，可能需要在飞书管理后台单独审批。

#### （三）订阅事件

飞书应用 → 事件配置 → 添加事件，订阅以下四类：

| 事件 | 说明 |
|---|---|
| 接收消息 | 消息收发核心事件 |
| 消息撤回 | 客户撤回消息时同步 |
| 群配置修改 | 群名称、群成员变更时同步 |
| 员工信息变化 | 员工信息变更时同步 |

### 步骤五：创建版本并发布

**操作位置**：飞书应用 → 版本管理与发布

1. 创建版本，版本号填写 1.0.0
2. 可用范围选择「所有员工」
3. 填写更新说明，保存
4. 点击「申请线上发布」
5. 由飞书管理员在飞书管理后台 → 工作台 → 应用审核中通过申请

**注意**：飞书的权限与事件配置在版本发布后才会生效。后续任何权限或事件的调整，都必须创建新版本并重新提交审核，否则配置不会生效。

### 步骤六：配置会话接入条件

**操作位置**：七鱼后台 → 飞书 IM 消息渠道配置 → 会话接入条件

| 选项 | 说明 | 适用场景 |
|---|---|---|
| 被 @ 后接入 | 客户 @ 机器人后进线，该群后续消息无需再次 @ | 推荐，适用于绝大多数客户群 |
| 全部消息接入 | 群内每条消息都会进线 | 仅适用于消息量极少的群 |

选择「全部消息接入」会使活跃群产生大量非业务会话，影响客服工作量统计与会话质量分析，建议保持默认的「被 @ 后接入」。

## 四、群聊使用说明

### 4.1 将机器人加入群

在飞书群中打开群设置 → 群机器人 → 添加机器人 → 搜索应用名称 → 添加。

机器人入群后不会自动发送欢迎语，客户首次 @ 机器人后会话即建立。

### 4.2 客户群的创建方式

飞书企业自建应用的可用范围仅覆盖本企业成员，因此客户群需由贵司创建，并将客户作为外部联系人邀请入群。

| 群类型 | 是否可用 |
|---|---|
| 企业内部群（全部为本企业成员） | 可用 |
| 外部群（贵司创建，成员含外部联系人） | 可用 |
| 外部群（客户创建，贵司成员被邀请） | 不可用 |

### 4.3 会话分配

飞书群会话的分配逻辑与网页、App 等渠道一致，遵循七鱼的统一分配规则。若需将特定客户群固定分配给指定客服，可在「高级分配 → 自定义规则」中配置，并将流转形式设为「指定」。

### 4.4 群内多客服接待

同一个群支持多位客服轮流接待，会话中会显示当前接待人。会话同一时间仅由一位客服持有，转交需由客服主动操作。

## 五、验收清单

接入完成后，请按以下四个阶段逐项验证。

### 阶段一：应用配置

- 应用已发布，状态为已上线
- 飞书工作台中可搜索到该应用
- 权限管理中九项权限均为已开通
- 事件配置中四类事件均已订阅
- 事件配置与回调配置的请求地址与七鱼生成的回调地址一致

### 阶段二：消息通道

- 机器人成功加入测试群
- 在群内 @ 机器人发送消息，七鱼工作台生成对应会话
- 客服在七鱼回复后，消息正常回显至飞书群
- 发送一条不带 @ 的消息，确认按预期处理

### 阶段三：会话功能

- 客户身份可正常识别，工作台显示客户名称而非默认访客编号
- 图片可正常收发
- 文件可正常收发
- 会话可正常结束
- 满意度评价可正常发出（如已开启）

### 阶段四：数据记录

- 会话可在七鱼会话记录中查询到
- 会话归属渠道显示为飞书
- 会话可纳入质检范围

## 六、常见问题排查

| 现象 | 可能原因 | 处理方式 |
|---|---|---|
| 七鱼保存后未生成回调地址 | App ID 或 App Secret 填写错误、含多余空格 | 清空后重新填写并保存 |
| 飞书保存回调地址时校验失败 | Encrypt Key 或 Verification Token 未填写或填写错误 | 核对两项信息，确认与七鱼侧一致 |
| 群内 @ 机器人无响应 | 权限未开通、事件未订阅、或权限变更后未重新发布版本 | 依次检查三项，重点确认是否已重新发布版本 |
| 消息可进入七鱼但客服回复无法送达 | 缺少消息发送权限，或未添加机器人能力 | 补充 im:message 权限与机器人能力后重新发布 |
| 客户身份显示为访客编号 | 缺少用户信息读取权限 | 补充 contact:user.base:readonly 权限后重新发布 |
| 群内非 @ 的消息不进入系统 | 接入条件设置为「被 @ 后接入」 | 属正常行为，如需全部接入请修改接入条件 |
| 图片或文件收发失败 | 缺少资源读写权限 | 补充 im:resource 权限后重新发布 |
| 群名称或成员变更未同步 | 缺少群组信息权限，或未订阅群配置修改事件 | 补充 im:chat 权限并订阅对应事件 |
| 权限修改后长期不生效 | 未创建新版本或未重新提交审核 | 在版本管理中创建新版本并申请发布 |
| 同一消息生成多条会话 | 旧版本缺陷 | 升级至最新版本后不再出现 |

## 七、使用限制

### 7.1 跨企业限制

飞书企业自建应用的可用范围仅覆盖本企业成员。由贵司创建、客户作为外部联系人加入的群可以正常接入；由客户在其所属企业内创建、贵司成员被邀请加入的群无法接入。

### 7.2 客户身份识别

外部联系人的飞书用户标识可能无法获取，同一客户在不同群中可能被识别为不同访客，导致客户标签、历史会话与客户档案无法自动关联。如需完整客户画像，建议结合其他身份信息进行关联。

### 7.3 消息类型支持

| 消息类型 | 支持情况 |
|---|---|
| 文本 | 支持 |
| 图片 | 支持 |
| 文件 | 支持 |
| 富文本 | 支持 |
| 引用消息 | 支持，被引用的图片、视频、文件同样可展示 |
| 表情 | 支持，按引用消息格式展示；未适配的表情以文字形式展示，此类消息不支持客服引用回复 |
| 位置 | 支持，展示位置名称 |
| 视频通话 | 支持，展示通话标题与开始时间 |

### 7.4 其他说明

- 客服可引用客户消息与自身消息并回传至飞书
- 飞书群的操作列表中提供「发起会话」按钮，可基于历史会话发起新会话
